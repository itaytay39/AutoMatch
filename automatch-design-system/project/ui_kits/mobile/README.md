# AutoMatch — Mobile UI Kit

מסך Dashboard מלא + רכיבי תמיכה ב-RTL עברית. בנוי כתבנית React inline-JSX, מותאם ל-mobile (390px). כל הרכיבים נשענים ישירות על `colors_and_type.css`.

## רכיבים

- `BottomNav` — ניווט תחתון בקפסולת glass עם 5 דסטינציות
- `SearchBar` — שדה חיפוש hero + chips
- `ListingCard` — כרטיס רכב עם תמונה, מחיר, sparkline
- `PriceGauge` — מד מחיר חצי-עיגול
- `StatPill` — pill מחיר טוב/סביר/יקר
- `SourceBadge` — תג מקור (yad2)
- `Sparkline` — גרף sparkline
- `Header` — כותרת מסך עם פעולות
